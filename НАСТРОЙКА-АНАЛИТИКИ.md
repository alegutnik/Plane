# Настройка аналитики PLANE

Код уже стоит на сайте. Сейчас счётчики **выключены** — пока не вписаны ID,
никакие внешние скрипты не грузятся и сайт работает как раньше.

---

## Шаг 1. Получить три ID

| Что | Где создать | Формат |
|---|---|---|
| Meta Pixel ID | business.facebook.com → Events Manager → Data Sources → Create → Web | 15–16 цифр |
| GA4 Measurement ID | analytics.google.com → Admin → Data streams → Web | `G-XXXXXXXXXX` |
| Clarity Project ID | clarity.microsoft.com → Add new project → Settings → Setup | 10 символов |

Вписать их в начало файла **`js/analytics.js`**:

```js
var ANALYTICS = {
  pixelId:   '',   // ← сюда
  ga4Id:     '',   // ← сюда
  clarityId: ''    // ← сюда
};
```

Порядок не важен — можно вписать один, остальные позже. Пустое поле
просто отключает соответствующий счётчик.

## Шаг 2. Return URL в кабинете WayForPay

`merchant.wayforpay.com` → для каждой платёжной кнопки прописать:

| Кнопка на сайте | ID кнопки | URL успеха (Return URL) |
|---|---|---|
| COMFORT €418 | `b1506e42af2d6` | `https://plane.anastasikarimova.site/success.html?p=comfort` |
| BUSINESS €478 | `b5bd2947dd630` | `https://plane.anastasikarimova.site/success.html?p=business` |
| ПЕРШИЙ КЛАС €918 | `b0616768c302e` | `https://plane.anastasikarimova.site/success.html?p=first` |
| Бронь 888 грн | `bbc70fafd3b8d` | `https://plane.anastasikarimova.site/success.html?p=booking` |

**URL неуспеха** (одинаковый для всех, если поле есть):

```
https://plane.anastasikarimova.site/fail.html
```

### Обязательно проверить после настройки

Сделай **одну реальную оплату** самой дешёвой кнопкой (или тестовой картой WayForPay) и проверь:

1. После оплаты браузер реально попал на `success.html`, а не остался на WayForPay.
2. На странице видно правильный тариф и сумму.
3. В Meta Events Manager появилось событие `Purchase`.

Если после оплаты страница не открылась или показала ошибку — напиши, поправлю.
Скорее всего WayForPay отправляет данные методом POST, который GitHub Pages не принимает;
тогда сделаем отдельные страницы без параметров или сменим хостинг.

## Шаг 3. UTM-метки на входящих ссылках

Без меток видно «пришло 100 человек», но не видно откуда. Ставь их **везде**,
где даёшь ссылку на сайт:

**Instagram, ссылка в шапке профиля**
```
https://plane.anastasikarimova.site/?utm_source=instagram&utm_medium=bio&utm_campaign=plane
```

**Reels / сторис**
```
https://plane.anastasikarimova.site/?utm_source=instagram&utm_medium=reels&utm_campaign=plane
https://plane.anastasikarimova.site/?utm_source=instagram&utm_medium=stories&utm_campaign=plane
```

**Telegram-канал**
```
https://plane.anastasikarimova.site/?utm_source=telegram&utm_medium=post&utm_campaign=plane
```

**Бот / рассылка**
```
https://plane.anastasikarimova.site/?utm_source=manychat&utm_medium=bot&utm_campaign=plane
```

**Платная реклама**
```
https://plane.anastasikarimova.site/?utm_source=facebook&utm_medium=cpc&utm_campaign=plane
```

Менять можно только `utm_source` и `utm_medium` — остальное оставляй как есть,
иначе отчёты рассыплются на десяток мелких строк.

## Что и где смотреть после запуска

| Вопрос | Где смотреть |
|---|---|
| Сколько людей зашло | GA4 → Отчёты → Обзор |
| Откуда пришли | GA4 → Привлечение трафика (разбивка по UTM) |
| Доскроллили ли до цен | событие `ViewContent` / `view_item` |
| Нажали «Придбати», но не купили | Meta Events Manager: `InitiateCheckout` минус `Purchase` |
| Что делают на странице, где зависают | Clarity → Recordings и Heatmaps |
| Окупается ли реклама | Meta Ads Manager → колонка Purchase ROAS |
| Кого догонять ретаргетингом | Meta Audiences → аудитория по `InitiateCheckout`, исключить `Purchase` |

Clarity начинает показывать записи сессий примерно **через сутки** после установки.

## Что стоит знать

**Покупок будет считаться чуть меньше, чем на самом деле.** Часть людей закрывает
вкладку сразу после оплаты, не дожидаясь возврата на сайт — такие покупки счётчик
не увидит. Обычно теряется 10–20%. Для оценки рекламы этого достаточно, но сверять
выручку нужно по кабинету WayForPay, а не по Pixel.

**Данные не появятся задним числом.** Всё, что не поставлено сегодня, за прошлый
месяц не соберётся.

**Цены меняются в одном месте.** В `js/analytics.js`, блок `PRODUCTS` — оттуда они
идут и в события, и на страницу success. Если менять цену на сайте, поменяй и там,
иначе в отчётах будет старая сумма.
